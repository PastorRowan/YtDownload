# Getting Started

## Prerequisites

Before running the project, make sure you have installed these into a console:

- Python 
- venv
- pip

## Installation 

Open a console enviroment with python, venv and pip installed.

Clone the repository:
```
git clone https://github.com/PastorRowan/YtDownload.git
```

Traverse to the project directory:
```
cd YtDownload
```

Create the virtual enviroment:
```
python -m venv venv
```

activate virtual enviroment:
```
.\venv\Scripts\activate.bat
```

Your console should now look like this:
```
(venv) path/to/project/dir ...
```

Install virtual enviroment dependencies:
```
pip install -r requirements.txt
```

Install binaries, depends on what operating system and architecture you are using.

Run the application
```
python main.py
```
